# 天气类市场结算口径示例库

> 本文档收集天气类预测市场的结算口径框架，供研究参考，不构成交易建议。

---

## 1. 纽约市最高温度超过 95°F (35°C)

| 字段 | 内容 |
|------|------|
| **问题定义** | 纽约市（JFK 机场气象站）指定日期的最高温度是否突破 95°F（35°C） |
| **地点/站点** | New York JFK International Airport (KJFK) |
| **时间窗** | 结算日 00:00-23:59 Local Time |
| **阈值** | 最高温度 > 95°F (35°C) |
| **数据源候选** | NOAA/NWS Hourly Observatons, Weather Underground, Ogimet |
| **争议风险点评** | 热岛效应可能导致市区温度高于机场；需确认使用机场数据还是城市平均 |

## 2. 伦敦每日降水量超过 10mm

| 字段 | 内容 |
|------|------|
| **问题定义** | 伦敦希思罗机场结算日降水量是否达到 10mm |
| **地点/站点** | London Heathrow Airport (EGLL) |
| **时间窗** | 结算日 00:00-23:59 UTC |
| **阈值** | 日累计降水量 ≥ 10mm |
| **数据源候选** | Met Office, OGIMET, Weather.com, World Weather Online |
| **争议风险点评** | 10mm 阈值对伦敦常见小雨可能偏高；需明确"降水"是否包含微量降雨；注意夏季雷阵雨突发性 |

## 3. 东京夏季最高气温创历史新高

| 字段 | 内容 |
|------|------|
| **问题定义** | 东京（大手町气象站）夏季是否突破历史最高温记录 |
| **地点/站点** | Tokyo (Ootemachi) - JMA 站点 |
| **时间窗** | 夏季（6-8月）任意一天 |
| **阈值** | 最高温度 > 历史极值（约 39.5°C） |
| **数据源候选** | JMA (日本气象厅), Ogimet, OGIMET |
| **争议风险点评** | 历史数据长度影响统计显著性；需确认是否使用修正后数据；热浪持续性是关键 |

## 4. 迈阿密飓风登陆佛罗里达

| 字段 | 内容 |
|------|------|
| **问题定义** | 结算周期内是否有飓风（≥ Category 1）登陆佛罗里达半岛 |
| **地点/站点** | 佛罗里达半岛任意地点 |
| **时间窗** | 飓风季（6月1日-11月30日） |
| **阈值** | 飓风级别 ≥ Saffir-Simpson Category 1，风速 ≥ 74 mph |
| **数据源候选** | NHC (National Hurricane Center), NOAA, Weather Underground |
| **争议风险点评** | 飓风路径预测难度大；"登陆"定义可能引发争议；快速转向可能使预测失效 |

## 5. 北京冬季 PM2.5 日均浓度 > 150 μg/m³

| 字段 | 内容 |
|------|------|
| **问题定义** | 北京定陵气象站结算日 PM2.5 日均值是否达到重度污染 |
| **地点/站点** | 北京定陵 (54511) 或 US Embassy Beijing |
| **时间窗** | 结算日 00:00-23:59 CST |
| **阈值** | 日均 PM2.5 > 150 μg/m³（中国标准重度污染） |
| **数据源候选** | China PM2.5 Data, US Embassy API, IQAir, China Air Now |
| **争议风险点评** | 站点选择影响结果；冬季采暖季高发；需确认用中国国标还是 WHO 标准（> 35 μg/m³） |

## 6. 芝加哥累计降雪量超过 12 英寸

| 字段 | 内容 |
|------|------|
| **问题定义** | 芝加哥奥黑尔机场结算周期（e.g., 24h）累计降雪量是否超过 12 英寸 |
| **地点/站点** | Chicago O'Hare (KORD) |
| **时间窗** | 结算周期内累计 |
| **阈值** | 累计降雪量 ≥ 12 inches (约 30.5 cm) |
| **数据源候选** | NWS, Ogimet, Weather Underground, NOAA COOP |
| **争议风险点评** | 降雪量测量受风漂移影响；"降雪量"vs"积雪深度"需明确；融雪后再结冰可能导致低估 |

## 7. 旧金山大雾导致能见度低于 0.5 英里

| 字段 |内容 |
|------|------|
| **问题定义** | 旧金山机场结算日是否有大雾导致能见度低于 0.5 英里 |
| **地点/站点** | San Francisco International Airport (KSFO) |
| **时间窗** | 结算日任意时刻 |
| **阈值** | 能见度 < 0.5 miles (约 800m) |
| **数据源候选** | NWS METAR, Ogimet, FlightRadar24 历史数据 |
| **争议风险点评** | 雾的形成和消散快，瞬时数据可能不准确；夏季"雾季"与秋季"火灾雾"不同源 |

## 8. 伦敦夏季出现 30°C+ 高温天数

| 字段 | 内容 |
|------|------|
| **问题定义** | 伦敦夏季（6-8月）最高温度 ≥ 30°C 的天数是否达到目标值 |
| **地点/站点** | London Heathrow (EGLL) 或 Kensington (市区) |
| **时间窗** | 整个夏季（6月1日-8月31日） |
| **阈值** | 天数 ≥ N 天（通常 N=5, 10, 15） |
| **数据源候选** | Met Office, Ogimet, ECAD (European Climate Assessment) |
| **争议风险点评** | 城市热岛效应导致不同站点差异大；历史平均值偏低，极端年份可能触发争议 |

## 9. 上海台风直接影响（100km 内）

| 字段 | 内容 |
|------|------|
| **问题定义** | 结算周期内是否有台风中心进入上海 100km 范围内 |
| **地点/站点** | 上海中心城区（31.2°N, 121.5°E） |
| **时间窗** | 台风季（7-9月） |
| **阈值** | 台风中心距离 ≤ 100km |
| **数据源候选** | JMA, CMA, JTWC, Weather Underground |
| **争议风险点评** | 台风路径预测误差；"直接影响"定义模糊（风速影响 vs 降水影响） |

## 10. 悉尼极端高温：连续 3 天 > 40°C

| 字段 | 内容 |
|------|------|
| **问题定义** | 悉尼天文台山（Observatory Hill）是否出现连续 3 天最高温度 > 40°C |
| **地点/站点** | Sydney Observatory Hill (94768) |
| **时间窗** | 结算期间连续 3 天 |
| **阈值** | 每日最高温度 > 40°C，且连续 3 天 |
| **数据源候选** | Bureau of Meteorology (BOM), Ogimet |
| **争议风险点评** | 澳大利亚夏季热浪定义明确，但城市热岛效应可能导致郊区站点数据偏低；40°C 阈值极端，历史上很少触发 |

## 11. 巴黎冬季积雪深度 ≥ 5cm

| 字段 | 内容 |
|------|------|
| **问题定义** | 巴黎奥利机场结算日积雪深度是否达到 5cm |
| **地点/站点** | Paris Orly (LFPO) |
| **时间窗** | 结算日 06:00-06:00 UTC 或当地观测时间 |
| **阈值** | 积雪深度 ≥ 5cm |
| **数据源候选** | Météo-France, Ogimet, World Weather Online |
| **争议风险点评** | 巴黎冬季降雪少见；积雪融化快，测量时间窗口关键；市区 vs 郊区积雪差异大 |

## 14. 新加坡连续降雨超过 5 天

| 字段 | 内容 |
|------|------|
| **问题定义** | 结算周期内新加坡是否出现连续 5 天以上降雨（日降水量 ≥ 0.2mm） |
| **地点/站点** | Singapore Changi Airport (WSSS) |
| **时间窗** | 结算周期连续天数 |
| **阈值** | 连续降雨天数 ≥ 5 天，日降水量 ≥ 0.2mm |

## 15. 纽约暴风雪导致机场关闭

| 字段 | 内容 |
|------|------|
| **问题定义** | 结算周期内纽约 JFK 机场是否因暴风雪导致航班大规模取消或关闭 |
| **地点/站点** | New York JFK (KJFK) |
| **时间窗** | 结算周期内任意时段 |
| **阈值** | 机场关闭 > 2 小时 或 取消航班 > 30% |
| **数据源候选** | FAA, FlightRadar24, NWS, news archives |
| **争议风险点评** | "机场关闭"定义模糊；航空公司调度决策可能不一致；需结合官方声明与实际运营数据 |

## 结算口径核对表 (Checklist)

- [ ] **地点/站点**：明确到具体气象站代码（如 KJFK、EGLL）
- [ ] **时间窗**：UTC 还是本地时区？起止时间？
- [ ] **阈值**：具体数值、单位（°C/°F, mm/inches）、触发条件（≥/>/</≤）
- [ ] **数据源**：首选、备选、是否有回溯历史
- [ ] **争议风险**：极端情况预案、站点迁移/设备变更、定义歧义
