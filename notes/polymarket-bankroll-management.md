# Polymarket 资金管理策略

## 概述

本文档探讨适用于 Polymarket 预测市场的资金管理策略，核心是 Kelly Criterion（凯利准则）及其变体。

---

## 1. Kelly Criterion（凯利准则）

### 1.1 原理

Kelly Criterion 由 John L. Kelly Jr. 于 1956 年提出，旨在最大化资本长期增长率。公式：

```
Kelly% = W - [(1-W) / R]
```

其中：
- **W** = 获胜概率（历史胜率）
- **R** = 盈亏比（平均盈利 / 平均亏损）

### 1.2 解读

| Kelly% | 建议仓位 |
|--------|----------|
| > 25% | 风险过高，建议限制 max 20-25% |
| 10-20% | 适中 |
| < 5% | 保守 |
| ≤ 0 | 不应下注 |

### 1.3 Polymarket 应用

在二元预测市场中：
- **W** = 你对该事件概率的估计 vs 市场隐含概率
- **R** = 1（因为赢时获得 p-1，输时失去 1）

简化为：
```
Kelly% = 你的概率 - 市场概率
```

### 1.4 示例

市场定价 YES = 40%（概率 0.4）
你通过研究认为真实概率 = 55%

```
Kelly% = 0.55 - 0.40 = 15%
```

每次下注使用资金的 15%。

## 2. Half-Kelly（半凯利）

### 2.1 为什么要用半凯利？

- **降低方差**：全 Kelly 导致资金波动剧烈
- **估计误差容错**：概率估计通常有误差
- **心理压力小**：更容易坚持策略

### 2.2 公式

```
Half-Kelly% = Kelly% / 2
```

### 2.3 效果对比

| 策略 | 期望增长率 | 资金波动 | 破产风险 |
|------|------------|----------|----------|
| Full Kelly | 最高 | 最大 | 较高 |
| Half-Kelly | 约 75% 最优 | 减半 | 极低 |
| Quarter-Kelly | 约 56% 最优 | 最小 | 极低 |

### 2.4 推荐

**对于 Polymarket 预测市场，建议使用 Quarter-Kelly（1/4 凯利）**，原因：
1. 概率估计误差大
2. 市场效率低但存在套利限制
3. 流动性约束

## 3. 仓位分配模型

### 3.1 固定比例模型

每次下注固定比例资金：

```
仓位 = 资金 × 固定比例%
```

**优点**：简单，不易破产  
**缺点**：不能根据信心调整

### 3.2 信心调整模型

根据个人信心程度调整仓位：

```
仓位 = Kelly% × 信心系数
```

信心系数建议范围：0.25 - 1.0

### 3.3 多市场分散模型

同时下注多个不相关市场：

```
单市场仓位上限 = 总资金 × 20-25%
```

防止单一事件黑天鹅导致巨大损失。

### 3.4 动态再平衡模型

根据资金变化动态调整：

```
新仓位 = 当前资金 × 目标比例%
```

定期（如每周）检查并再平衡。

## 4. Polymarket 特定考虑

### 4.1 流动性约束

- 检查 order book 深度
- 大额订单可能滑点严重
- 分批建仓降低冲击成本

### 4.2 事件风险

- 突发新闻可能导致概率剧烈变化
- 设置止损/止盈点
- 避免单一事件暴露 > 25% 资金

### 4.3 手续费影响

- Polymarket 交易有手续费
- 考虑费用后的净期望值
- 频繁交易会侵蚀利润

### 4.4 建议策略

```
起始资金: $1000

单笔最大仓位: 5-10% 资金
日最大仓位: 20% 资金
周最大仓位: 40% 资金

使用 Quarter-Kelly 计算基准仓位
根据信心系数调整（0.25-1.0）
止损线: -20% 单日, -40% 周
```

---

## 5. 实施步骤

1. **记录历史交易**：至少 50-60 笔交易计算 W 和 R
2. **计算基准 Kelly**：基于历史表现
3. **应用衰减系数**：使用 1/4 或 1/2
4. **设置仓位上限**：不超过 20-25%
5. **监控并调整**：每月回顾表现，动态调整

---

## 6. 风险提示

- Kelly Criterion 假设历史表现代表未来
- 概率估计误差会导致实际仓位偏离最优
- 预测市场受突发事件影响大
- 建议仅用可承受损失的资金参与
